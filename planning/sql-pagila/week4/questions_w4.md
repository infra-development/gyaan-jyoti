# Week 4 Questions

## Window Functions & Analytical SQL

---

# Instructions

- Solve the questions in order.
- Do not skip difficult questions.
- Think about the business problem before writing SQL.
- Draw the relationship path whenever multiple tables are involved.
- Identify the required Window Function before writing the query.
- Use **only the standard PostgreSQL Pagila database**.
- Do not modify the database schema.
- Focus on writing clean, readable, and maintainable SQL.
